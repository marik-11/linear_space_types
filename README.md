# Line-size types of finite linear spaces

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24567131.svg)](https://doi.org/10.5281/zenodo.24567131)

This repository contains the Python implementation and computational data accompanying the paper:

**Mark Kim, "Line-size types of finite linear spaces: an exhaustive computation up to fifteen points" (November 26, 2026).**

The paper studies the number of distinct types of finite linear spaces on \(n\) points. A type is the multiset of sizes of all lines containing at least three points.
